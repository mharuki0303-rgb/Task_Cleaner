# あたまの整理箱 (Task_Cleaner)

その日のやることを書き出すと Claude がタスクにまとめ、日・週・月の達成率をヒストグラムと辛口の五段階評価で振り返れるタスク管理ページです。

## 機能

- 日付ごとのタスク管理（優先度は 高 / 中 / 低 のプルダウン）
- 書き出したメモを「Claudeでまとめる」でタスク化（所要時間・次の一手・分類つき）
- 日・週・月の達成率グラフと、評価 1〜5 の辛口コメント
- 評価ごとの日数の分布

## 使い方

`index.html` をブラウザで開くだけで動きます（ビルド不要）。

- claude.ai のアーティファクトとして開いた場合：Claude によるまとめ機能と、アカウントへのデータ保存が使えます。
- それ以外（ローカルで開く・GitHub Pages など）：手動でのタスク追加と振り返りは使えます。データはブラウザの localStorage に保存されます。「Claudeでまとめる」は動きません。

## 評価の基準

| 評価 | 達成率 |
| --- | --- |
| 5 | 90% 以上 |
| 4 | 75% 以上 |
| 3 | 55% 以上 |
| 2 | 35% 以上 |
| 1 | 35% 未満 |
